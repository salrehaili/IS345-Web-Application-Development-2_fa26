## About This Repository

This repository contains practical examples developed for **IS345 – Web Application Development 2**.

The examples are designed to help students understand server-side web development using Node.js, Express.js, and database technologies.

Each example demonstrates important concepts covered during the course and provides an opportunity for students to explore, run, and modify working applications.

## Learning Objectives

By studying these examples, students will learn how to:

- Build web applications using Node.js and Express.js.
- Understand and implement the Model-View-Controller (MVC) architecture.
- Organize applications into models, views, controllers, and routes.
- Connect Express.js applications to SQLite databases.
- Perform database operations using SQLite3.
- Use Sequelize ORM to interact with relational databases.
- Understand the differences between direct SQL queries and ORM-based database operations.

## Available Examples

### Example 01: Express.js MVC with SQLite3

**Folder:** `db_mvc`

This example demonstrates how to develop an Express.js application using the MVC architecture and SQLite3 for database operations.

**Key concepts:**
- Express.js application setup
- MVC architecture
- Routing and controllers
- SQLite3 database connection
- Executing SQL queries

### Example 02: Express.js MVC with Sequelize

**Folder:** `examples/02-express-mvc-sequelize`

This example demonstrates how to develop an Express.js application using the MVC architecture and Sequelize ORM.

**Key concepts:**
- Express.js application setup
- MVC architecture
- Sequelize ORM configuration
- Defining database models
- Performing database operations using Sequelize

## Requirements

Before running the examples, make sure you have installed:

- Node.js
- npm
- Visual Studio Code (recommended)

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/IS345-Web-Application-Development-2.git
```

**2. Navigate to an example**

```bash
cd IS345-Web-Application-Development-2/examples/01-express-mvc-sqlite3
```

**3. Install dependencies**

```bash
npm install
```

**4. Run the application**

```bash
node app.js
```

*Note: The startup command and application port may differ between examples. Refer to the README inside each example folder.*

## Instructions for Students

1. Review the source code before running the application.
2. Identify the responsibilities of models, views, and controllers.
3. Run the example on your local computer.
4. Modify the code to experiment with the concepts discussed in class.
5. Compare the SQLite3 and Sequelize implementations.
